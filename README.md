# Maritime Management System -  Server
A Train Tracking

## Usage
### Running [DEV]
`go run . start`

### Running [PROD]
`TrainTracking start`

### Other command
#### Generate your feature
`go run . generate feature <FeatureName>`

#### Generate your migration
`go run . generate migration <SeederName>`

#### Generate your seeders
`go run . generate seeder <SeederName>`

#### Execute your migration (up)
`go run . db migrate`

#### Execute your migration (rollback)
it will rolling back your last migration
`go run . db rollback`

#### Execute your seeders
`go run . db seed`

#### Execute your migration (rollback)
`go run . db rollback`
